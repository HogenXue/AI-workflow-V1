# Evidence

Logs contain actual isolated results, with trailing whitespace and terminal CR
normalized in public text only. Raw originals and the runner remain privately in
the durable audit directory named in verification.md. RED/first-run logs remain
historical evidence; final passing runs supersede only the identified failures.
Runtime provenance, source hashes, independent reviews, branch history and restore
proof are in research/. No real host MCP/configuration snapshots are included.
