# Pelican cycling animation

## Goal
Create one HTML file containing a 2D SVG animation of a pelican riding a bicycle.

## Requirements
- Deliver `pelican-cycling.html` in the repository root, runnable offline by opening the file.
- Show a recognizable pelican riding a bicycle in an original, polished coastal illustration.
- Animate pedaling, wheels and scenery coherently; provide pause/resume and speed controls.
- Adapt to desktop and mobile viewports, with accessible labels and reduced-motion support.
- Keep all assets, styling and script inline. No external dependencies or network requests.

## Acceptance Criteria
- [x] HTML opens successfully and shows the complete SVG illustration.
- [x] The pelican, bicycle, moving wheels and pedaling are clearly visible.
- [x] Pause/resume and speed controls work, including keyboard use.
- [x] Narrow screens retain the complete scene without horizontal page overflow.
- [x] Reduced-motion preference starts the animation paused.
- [x] Browser verification and a scope-specific review are recorded.

## Boundaries
Do not modify existing product code, host settings, unrelated files, or Git state. No commit, push or archive requested.
